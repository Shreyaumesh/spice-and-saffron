# Spice & Saffron 🍛

A simple restaurant website built using HTML and CSS. It showcases an Indian restaurant with a warm design and a menu featuring popular Indian dishes.

## Features
- Home section with a background image
- About section
- Menu with dishes and prices
- Chef's Special section
- Why Choose Us section
- Contact section with a table reservation form
- Footer with navigation links
- Responsive layout for mobile screens

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code.
